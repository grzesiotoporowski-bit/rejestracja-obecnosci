# Rejestracja obecności – aplikacja webowa

## Opis projektu
Projekt przedstawia prostą aplikację webową służącą do rejestracji obecności.
Aplikacja umożliwia dodawanie wpisów za pomocą formularza oraz ich
wyświetlanie w formie tabeli. Dane są zapisywane lokalnie w przeglądarce
użytkownika, dzięki czemu nie znikają po odświeżeniu strony.

Projekt został wykonany jako aplikacja typu frontend i udostępniony online
za pomocą GitHub Pages.

---

## Funkcjonalności
- formularz rejestracji obecności (imię, nazwisko, grupa, temat zajęć, status, komentarz),
- wyświetlanie zapisanych wpisów w tabeli,
- trwały zapis danych przy użyciu LocalStorage,
- możliwość wyczyszczenia danych,
- eksport zapisanych danych do pliku CSV,
- działanie aplikacji bez potrzeby serwera.

---

## Zastosowane technologie
- HTML5 – struktura strony,
- CSS3 – stylizacja interfejsu użytkownika,
- JavaScript – logika aplikacji oraz obsługa danych,
- LocalStorage – lokalne przechowywanie danych,
- GitHub Pages – publikacja aplikacji online.

---

## Jak działa aplikacja?
1. Użytkownik wprowadza dane w formularzu.
2. Po kliknięciu przycisku „Zapisz wpis” dane są zapisywane w LocalStorage.
3. Zapisane wpisy pojawiają się w tabeli obecności.
4. Dane pozostają zapisane nawet po odświeżeniu strony.
5. Użytkownik może pobrać listę obecności w formacie CSV.
